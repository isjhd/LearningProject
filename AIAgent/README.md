# AI Agent



## 简介

### 介绍

使用 Spring AI + Google ADK + Tauri（+Typescript），结合运行时智能体设计，涵盖；`Agent WorkFlow`、`上下文管理（对话追踪、搜索、提示词）`、`意图识别（+LLM）`、`混合窗口裁剪`、`动态提示词（ Prompt 组装器、里程碑追踪）`等，核心设计，构建一整套 AI Agent 智能体服务工具。



### 作用

为你的服务器做智能化运维服务管理。

如；`日志分析`、`系统健康度巡检`、`内存泄漏排查`、`复杂项目链路耗时处理`、`项目压测优化建议等等场景`。

AI Agent 要解决的就是一整条研发交付路径服务，包括；研发设计（spec规约）、工程编码（WaLiCode）、项目上线/运维（WaLiSSH）等。



### 技术栈

- JDK 17
- Maven 3.8.*
- SpringBoot 3.4.3
- Spring AI 1.1.5
- Google ADK 1.2.0
- MySQL 8.x
- Docker
- Tauri + React + Typescript



Spring AI + Google ADK + Tauri（+Typescript）

```
【客户端层】Tauri + TypeScript
  ↓（交互/窗口/本地缓存）
【业务逻辑层】Spring AI（WaLiCode 架构内核）
  ✅ 核心：Agent WorkFlow | 上下文管理 | 动态Prompt | 意图识别 | 窗口裁剪
  ↓（调度/编排）
【底层AI层】Google ADK（Gemini 大模型）
  ✅ 核心：LLM推理 | 谷歌搜索 | 运行时智能体算力
```

- Spring AI：后端 AI 业务编排。
  - 能力：多模型适配、统一API、结构化输出(响应映射到类)、支持RAG与向量存储。
  - 适用场景：智能客服与多轮对话、文档问答与知识库检索、多模态生成(文生图、图生文)。
- Google ADK：构建、调试和部署复杂的多智能体系统
  - 功能：实现复杂任务的协调和委派、丰富的工具生态、与Google生态深度集成、灵活部署、事件驱动架构
  - 适用场景：与Google服务紧密集成的自动化助手或分析工具
- Tauri（+Typescript）：跨端桌面客户端
  - 轻量级跨端桌面应用框架。
  - TypeScript，用于编写 Tauri 前端业务逻辑。
